# 🫀 Generative AI for Personalized Heart Disease Education

## Overview
This project integrates:
- Machine Learning (Random Forest) for heart disease risk prediction
- Large Language Models (LLMs) for personalized health education
- Prompt engineering for safety and medical scope control

The system is designed **for educational and research purposes only**.

---

## Features
- Predicts heart disease risk probability
- Converts ML output into understandable risk levels
- Generates safe, general lifestyle advice using an LLM
- Includes hallucination-aware prompting

---

## Tech Stack
- Python
- scikit-learn
- Pandas / NumPy
- Ollama (LLaMA 3)
- Gradio
